# Specs

Plans and specs for work that is coming or in progress, one file per topic: `specs/<topic>.md`.
Once the work is built, describe how it works in `app_docs/` and leave the spec as the record of the plan.
Existing plans still live in `docs/` (`docs/PLAN.md`, `docs/OBD2-PLAN.md`) and lane briefs in `docs/lanes/`.
