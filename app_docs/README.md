# App Docs

How the parts of Sierra Auto that are already built work, one file per feature or subsystem: `app_docs/<feature>.md`.
Say where the code and tests are, what was verified on the phone or truck, and what is still **unverified**.
Earlier write-ups of built features still live in `docs/` (for example `docs/VOICE.md`, `docs/DUPLEX.md`, `docs/STUDIO54.md`).
